# แผนการถ่ายภาพดาวเทียม THEOS-2 พื้นที่ทดสอบ

หน้าเว็บแสดงปฏิทินแผนการถ่ายภาพ (Off-nadir) อ่านข้อมูลจากไฟล์ Excel ในโฟลเดอร์ `xlsx/` อัตโนมัติ

## โครงสร้าง
- `index.html` — หน้าเว็บ
- `xlsx/` — วางไฟล์ `.xlsx` ของแต่ละพื้นที่ที่นี่ (ชื่อไฟล์ = ชื่อพื้นที่ เช่น `Tuz_Golu.xlsx`)

## อัปเดตข้อมูล
เข้าโฟลเดอร์ `xlsx` → Add file → Upload files → ลากไฟล์ใหม่ (ชื่อเดิมจะถูกแทนที่) → Commit
เพื่อนที่เปิดลิงก์เดียวกันจะเห็นข้อมูลใหม่หลังรีเฟรช
